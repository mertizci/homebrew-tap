# homebrew-tap

Homebrew tap for Mert IZCI's apps.

## Browser Picker

A menu bar app that routes links to the right browser and profile.

```bash
brew install --cask mertizci/tap/browser-picker
```

## Duckows

A Windows-style taskbar for macOS — a full-width bar on every display with a
Start menu, your open windows by name, and a system tray.

```bash
brew install --cask mertizci/tap/duckows
```
